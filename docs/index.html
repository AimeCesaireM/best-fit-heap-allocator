Allocator Overview

Best-Fit Search

The allocator keeps a doubly linked list of free blocks. Each call to malloc scans that list to find the smallest block that can satisfy the request. The block is optionally split when there is room for a new header and payload.

Pointer Bumping

When no usable free block exists, the allocator “bumps” a pointer to carve fresh space from the reserved heap region. This visualization tracks the bump pointer so you can see when the heap grows.

Block Alignment

All allocations are aligned on 16-byte boundaries. The visualizer highlights padding added to meet alignment requirements so you can see where internal fragmentation appears.
